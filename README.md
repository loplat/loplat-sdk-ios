## SPM 기반 종속성 추가하기

loplat SDK (Plengi SDK)는 현재 iOS 환경의 최신 종속성 관리 도구인 SPM을 지원하고 있으며 아래의 Repository를 통해 제공되고 있습니다.
- https://github.com/loplat/loplat-ios-spm

아래의 경로를 따라가서 
[Xcode] - [Project] - [Package Dependencies]에서 `loplat-ios-spm`을 프로젝트의 타겟에 추가해주세요.

Package Dependencies에 `MiniPlengi`가 보인다면, 종속성 추가하기 작업은 완료되었습니다.
